## Overview

[Build360.ma](https://build360.ma) is a premium agency platform based in Morocco specializing in 3D virtual tours, high-resolution HDR photography, and architectural floorplans. The platform serves as both a public portfolio to showcase immersive Matterport scans for clients (in real estate, hospitality, riads, and retail) and a backend service to publish virtual walkthroughs with interactive hotspots.

## Key Features

- **Matterport & WebGL Integration**: Seamless embedding and custom UI styling for immersive 360-degree virtual walkthroughs.
- **Client Lead Generation**: Highly optimized request forms and appointment scheduling tool tailored for businesses to request custom scans.
- **Multilingual Support**: Supports both French and English audiences seeking professional scan services across Morocco (Rabat, Casablanca, Marrakech, Tangier).
- **Interactive Floorplans**: High-quality 2D/3D floorplans and BIM exports integrated directly into property listings.
- **High-Performance Image Optimization**: Lazy loading and CDN integration for large-format HDR photos and promotional videos.

## Technologies Used

- **Next.js**: For a fast, SEO-optimized framework with pre-rendered pages to capture organic traffic from search queries.
- **React & Framer Motion**: To build elegant micro-interactions, smooth scroll animations, and dynamic transitions.
- **Tailwind CSS**: Used to design a custom dark theme that highlights colorful virtual media and photography.
- **Vercel & Cloudinary**: For fast assets delivery, ensuring media-heavy pages load in under a second.

## Challenges and Learnings

Deploying a media-heavy website that includes large 3D tours, videos, and high-resolution galleries without sacrificing SEO and page performance was a major technical challenge. To overcome this, we implemented dynamic code splitting, loading embeds only after user interaction, and using WebP/WebM optimized assets. This improved the mobile performance score to over 90 on Google PageSpeed.

## Outcome

Build360.ma has established a strong digital presence in the Moroccan prop-tech market, serving major companies and hotels. The optimized design resulted in a **50% increase in inbound leads** and became a key marketing tool to showcase the value of virtual tours to real estate and tourism businesses.
